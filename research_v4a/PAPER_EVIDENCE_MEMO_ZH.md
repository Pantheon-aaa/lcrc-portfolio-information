# research_v4a 论文证据留存：平均代价受控的决策兼容性

整理日期：2026-10-12。原始实验提交：`170a6fb5fa82454d56e236b2326f3617062afae8`；实验起点：`edac208d27e8751faab5a2ca94a1cd267cd4439b`。

本文用于后续论文写作、结果引用和补实验交接。它整理已保存的结果，不构成新一轮实验，不更新冻结阈值，不改变最终审计状态。原始报告中的“仅本地提交／未推送”描述的是当时的交付状态；随后已按用户指令发布实验分支，本次将结果与本文一起合入 main。合并代码不等于通过数值验收。

## 1. 本轮最值得保留的认识

本轮确实获得了有价值的正面结果：允许少量后验平均 regret 增量时，仍能保留相当一部分达标率收益；这种现象不只出现在对称三模型反例，也出现在独立生成的非对称确认族。分块模型进一步展示了：决定决策表现的不只是观测数量，还有观测能否区分影响配置的风险模型。兼容性价格使这些现象能够用“覆盖哪些模型需要付出多少平均代价”来解释。

目前最稳妥的论文主线是**刻画成功概率与平均代价的可计算前沿，并解释不同信息结构下的平台**。本轮尚不支持“精确 A1-B 的达标率普遍显著优于简单贪心”，也没有完成“每个实例都达到要求精度”的数值验收。正面机制、方法排名、计算效率和证书完整性应分开陈述。

## 2. 研究对象、数据口径与冻结设计

对候选模型 j，记 regret 为 R_j(w)，后验为 p。MA 最小化 L_p(w)=Σ_j p_j R_j(w)，最优值记作 L_p*。本轮求解：

`max_w Σ_j p_j 1{R_j(w)≤ε}，约束 L_p(w)−L_p*≤βL_p*。`

主目标闭合后，再在所有主目标最优组合中最小化平均 regret。空成功集合合法；β=0 按协议返回 MA；不以正数 floor 替代近零 L_p*。决策器不能接收真实模型编号。

| 项目 | 本轮口径 |
| --- | --- |
| 范围 | 仅 A1-B；无方向 B、真实回测、模型失配实验 |
| S1 | d=M∈{3,6,10,20}，完整 280 个预算查询，另含价格跳点检查 |
| S2 风险族 | 非对称、隐藏曲率、分块三类；各 2 个开发族、4 个确认族；M=6 |
| 约束 | 长仓、权重和为 1、单资产上限 0.2（S2） |
| 观测 | Separated／Joint 均使用两个独立时点，每块共 d 个标量 |
| 样本量 | n∈{0,32,256,1024}；1024 由开发信息界触发，未读取方法胜负 |
| 公共 ε/u_f | 0.0016512875809021929、0.011863236445932387、0.13477080327614221 |
| 主预算 | β=0.10、0.25；0、0.5、∞ 单列端点或附表 |
| 完成数据 | 444 个开发视图；4344 个确认视图，其中 4320 个非零数据集、24 个零样本 mask 视图 |
| 独立统计单位 | 12 个确认风险族；每类 4 个，不能把观测重复或方法行当作独立风险族 |
| S3 | 18 个新实例，完整 600 个同目标求解查询，180 个 case—budget 组 |

主结果先在每族内对真模型、正样本量、mask、公共阈值等权，再对族等权。几何阈值 ε/Γ(all) 的结果只作诊断，不混入主检验。零样本两种 mask 是同一先验的视图，不是额外独立数据。

## 3. 正面发现一：小平均代价对应可见的达标率收益

| 方法 | 实际达标率 | 实际平均 regret / MA | p95 regret | 族内最坏模型达标率的族均值 | 严格预算认证率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| MA | 84.41% | 1.0000 | 0.005587 | 80.74% | 零预算浮点认证开放 |
| A1-B，β=0.10 | 86.43% | 1.0030 | 0.005631 | 85.14% | 60.76% |
| A1-B，β=0.25 | 87.64% | 1.0281 | 0.005631 | 85.69% | 61.48% |
| A1-B，β=0.50 | 89.39% | 1.1446 | 0.006510 | 86.02% | 61.85% |
| 新版 A1-B，β=∞ | 90.58% | 1.3102 | 0.008009 | 86.11% | 无有限预算限制 |
| 旧 A1，在同一批新数据上 | 90.56% | 1.8562 | 0.009227 | 86.11% | 无有限预算限制 |

10%／25% 后验预算下，相对 MA 的达标率分别增加约 **2.01／3.23 个百分点**，保留新版无预算额外收益的 **32.7%／52.3%**。实际平均 regret 在这个平衡设计中只增加约 **0.30%／2.81%**。这些是按冻结口径计算的描述性结果，不能把实际平均增幅解释成对所有真模型的逐实例保证。

尾部代价也必须同时保留：两档主预算的 p95 略高于 MA；确定失败条件下的平均 regret 从 MA 的 0.003615 上升到约 0.003867／0.004350。提高“达标”概率不意味着所有损失指标都改善。该条件均值只包含确定失败，不将边界未决事件强行归类。

较高的最坏模型达标率是有用的补充现象，但表中是“各族内最坏模型值再取族均值”，不是对所有模型、所有族的统一下界。

证据：[overall_summary.json](results/overall_summary.json)、[完整报告](REPORT_ZH.md)、[预算前沿图](figures/S2_budget_frontier.png)。预算未认证实例没有从表中删除；因此论文不能仅凭这张表宣称严格预算保证已在全部实例上实现。

## 4. 正面发现二：非对称新族上的收益具有重复性

下面列出 A1-B 相对 MA 的逐族实际达标率增量，单位为百分点；它们沿用主实证的等权口径。

| 结构及确认族编号 | β=0.10 | β=0.25 |
| --- | ---: | ---: |
| 非对称 0，d=10 | +4.44 | +6.48 |
| 非对称 1，d=12 | +3.98 | +5.37 |
| 非对称 2，d=10 | +4.35 | +5.65 |
| 非对称 3，d=12 | +3.06 | +4.54 |
| 分块 0 | +2.78 | +5.56 |
| 分块 1 | 0.00 | +2.78 |
| 分块 2 | +5.56 | +5.56 |
| 分块 3 | 0.00 | +2.78 |
| 隐藏曲率 0、1、2、3，各族 | 0.00 | 0.00 |

四个非对称确认族在两档预算下均为正，说明现象超出了原始对称反例。分块族在较大预算下全部出现收益，也符合价格台阶可能导致小预算“无动作”、跨过门槛后才提高覆盖率的解释；是否某一具体变化恰好对应一个已认证跳点，仍须逐实例价格证据支持。

隐藏曲率在主公共阈值下，MA 与 A1-B 都已经 100% 达标。这里存在明显的天花板效应，不能将零增量写成“隐藏曲率模型普遍无价值”，也不能把它删掉后重新定义本轮主排名。未来若设计更有分辨率的阈值，必须另立开发方案和独立确认族。

证据：[family_summary.json](results/family_summary.json)、[逐族图](figures/S2_family_effects.png)。每类只有四个确认族，上表是机制支持和逐族描述，不等于单独的类内显著性结论。

## 5. 正面发现三：信息平台为成功概率提供解释

Separated 与 Joint 每块观察的标量数相同，但保留的协方差信息不同。分块模型中，Separated 只能识别模型所属的可辨识类，类内三个模型仍可能不可区分；Joint 可以使用跨组信息。保存的 β=0.10、三个公共阈值及四族平均图中，分块 Separated 曲线接近约 1/3 平台，Joint 接近 1；这只是该固定汇总切片，不能推广成所有 ε 和 β 下的通用平台值。

非对称结构的 Joint 在有限样本下更快接近高成功率，Separated 也随信息增长接近其平台；隐藏曲率在这组公共阈值下则早已饱和。它们共同说明，观测的可辨识结构和决策容忍度必须一起讨论。

平台由六模型独立枚举及价格复核得到，不能把有限样本方法结果当作理论平台反推。预算间隔为零或数值未决时应保留左右界，不能套用严格稳定收敛结论。

证据：[S2_platforms.jsonl](results/S2_platforms.jsonl)、[信息与平台图](figures/S2_information_platform.png)、[理论审核](THEORY.md)。该图为选定 β 的族／阈值平均展示；论文附录须保留逐族逐阈值结果。

## 6. 正面发现四：兼容性价格与精确台阶有直接数值支持

对成功模型集合 G，令 K_G 为所有 R_j(w)≤ε 的共同可行域，c_G 为其中最低后验平均 regret 增量。价格表示为：

`最优成功质量 = max_{G: c_G≤βL_p*} p(G)。`

这使连续持仓的决策问题转化为有限集合上的覆盖质量与价格之间的权衡。全局二级选择再取所有主目标最优集合的最低价格；只在任意选中的一个集合内优化不够。

S1 完整 280 查询通过解析质量核验，保存了全基数价格、跳点及独立数值边界检查。其意义是支撑一个可解释、可画出完整台阶的多资产机制，而不是再添加一个“算法在自定义反例胜出”的分数。置换对称约简必须先有证明，并与通用求解结果分栏；不得把对称族的计算便宜当成一般非对称算法速度。

证据：[S1_validation.json](results/S1_validation.json)、[S1_boundaries.json](results/S1_boundaries.json)、[S1_analytic_prices.json](results/S1_analytic_prices.json)、[完整台阶图](figures/S1_exact_staircases.png)、[Gate 0](results/gate0.json)。这些局部通过不覆盖最终审计指出的其他证书问题。

bootstrap 使用固定种子、10,000 次分层族级重采样；检验使用族级双侧符号随机化及边界不确定性保守处理，四项一起 Holm 校正。bootstrap 区间与保守检验回答的量不同，区间为正而校正 p 未显著不能被择一汇报。四项均未达到预设显著性标准。

全部 CVaR ρ=0.25、0.5、1 的结果都在原报告中保留；它们在本轮主预算下的达标率低于 A1-B，但部分尾部 regret 更小。这是不同目标的权衡，不是对 CVaR 的普遍否定。旧 A1 的较高平均代价提示全局二级选择值得研究，但新版还有开放证书，不能把新旧差额全部宣称为已经认证的精确破同分收益。

证据：[primary_tests.json](results/primary_tests.json)、[family_paired_effects.json](results/family_paired_effects.json)。所有区间包含边界不确定性，缺失或开放状态未被择优剔除。

## 8. 理论贡献与论文措辞边界

| 层次 | 可以保留的内容 | 不应超出的表述 |
| --- | --- | --- |
| 已审核的条件性命题 | 有限模型价格前沿、空集合处理、对称族公式、满足预算间隔的平台解释 | 不等于所有数值实现通过，也不自动证明发表优先性 |
| 经典工具 | MA 的后验均值最优性、Helly／最小冲突、混合整数主问题、凸定价、affinity 界 | 不应重新命名为原创理论 |
| 待收敛贡献 | 具体组合问题中的精确平均代价价格、预算与部分识别的共同解释、可认证实现 | 需要补完数值缺口和独立文献定位 |
| 实证支持 | 新非对称族的成功—代价前沿、分块信息平台、缓存效率 | 不支持真实市场超额收益、模型失配稳健性或普遍优于贪心 |

已有 [THEORY.md](THEORY.md) 记录了与 Park–Lee、Multiple Correct Answers 等近邻的关系。本轮不再将“最小不相容集合决定错误指数”作为原创主张。这里留存的是既有理论审核结论，并非一次新的完整文献综述。

可作为论文结果段落的保守初稿：

> 在三个预设合成结构的 12 个独立确认风险族上，平均 regret 预算为 MA 后验最优值的 10% 和 25% 时，预算兼容性策略的总体实际达标率分别为 86.43% 和 87.64%，高于 MA 的 84.41%。这一收益在四个非对称族上均可观察，并保留约三分之一和二分之一的无预算额外收益。该策略与预算贪心的达标率接近；预设四项比较未通过保守多重检验。逐实例严格预算与二级精度仍有开放证书，故这些结果是对预算前沿机制的支持，而非完整数值认证或普遍算法优越性结论。
