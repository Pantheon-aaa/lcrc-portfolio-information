# 平均代价受控兼容性学习的理论核查

本轮研究在 `Δ_p(w)≤βL_p*` 下最大化后验 ε-成功质量。附件原文保存在 INPUT_PROTOCOL_ZH.md；其中的定理是条件性数学结论，并不等于已经确认原创性。本文件记录证明的关键依赖与计算证书的对应。

| 结果 | 审核结论 | 实现及限制 |
| --- | --- | --- |
| 兼容价格前沿 | 给定正定模型、紧凸域成立 | 任意可行组合映射到其成功集合，反向取该集合的最低价格见证；空集合必须保留 |
| 台阶与价格单调性 | 有限子集论证成立 | 不保证允许一点代价就有一点成功提升 |
| 预算感知 Helly 结论 | 成立，属经典工具应用 | 包含预算集合的最小空交证书至多含 k 个模型，否则至多 k+1 个模型；不推出多项式算法 |
| 精确多资产公式 | 逐步代数与凸对称化论证通过，另做数值核验 | 先证明置换平均不损可行性再降为两组坐标；不是猜测一个对称驻点 |
| 部分识别平台 | 在给定预算间隔和有限模型假设下成立 | 是先验加权实际成功率的极限，不是每个真模型都有相同极限 |
| 零类内平均 regret | 需单独处理 | 类内正先验与非负 regret 推出共同最优解；数值下溢不能冒充该结构 |
| Affinity 有限样本界 | 对独立观测块成立 | 使用完整 mask 高斯子矩阵；这是充分界，不是新的最优错误指数 |
| 后验扰动界 | 附件式（26）的预算收紧与两次 TV 误差论证成立 | 右侧收紧预算须非负；近预算跳点允许集合改变 |
| 几何割与价格割 | 由包含关系和弱对偶成立 | 价格割依赖后验；主质量闭合不代表全局最低价格闭合 |

## 价格前沿的证明结构

令 `K_G=∩_{j∈G}{R_j≤ε}`，`c_G=min_{K_G}Δ_p`。对任意满足预算的 w，其全部成功模型组成 G，故 `c_G≤Δ_p(w)≤B`。反过来，`c_G≤B` 的最低价格见证至少覆盖 G。因此最优成功值正好等于 `max_{c_G≤B}p(G)`。有限个子集给出台阶；紧性、连续性及强凸性分别保证极小点存在和价格见证唯一。全局二级价格是所有达到最大成功值的组的最低价格，不能仅优化任意一个索引选出的组。

## 精确相变的独立核查

对附件矩阵逐项验证 `mean_j Q_j=I`、`H_j w0=v_j` 和切空间二次展开。对任意 G，将持仓在 G 内及其补集内做置换平均，凸性保证每个组约束与预算保持可行，故最小代价解必为两组等权。代入后选中模型 regret 为 `L0−t√η_m r+a_m r²/2`，取满足约束的较小非负根得到价格 `r²/2`。非选中坐标的一阶项为正且二次项非负，因此不会暗中多覆盖模型。持仓偏移受附件的 t 上界控制，满足长仓和上限。

Gate 0 使用完整坐标的 Clarabel 与独立 CVXPY 建模检查价格及 Γ，而非将解析答案填入通用求解器。S1 的对称约简成绩单列，不能当作一般非对称求解速度。

## 部分识别及有限样本界

同类模型的观测密度完全一致，类内后验比例恒等于归一化先验；不同类之间正 KL 和大数定律使类外后验质量 z 收敛到零。紧域上 regret 有界，得到 `|c_G(p)−c_G(q)|≤2Rmax TV(p,q)`，而预算的变化至多 `βRmax TV`。预算间隔为正时可行子集族最终稳定，最优后验成功值收敛到该类的平台。再用 Bayes 条件期望恒等式和有界收敛，得到先验加权实际成功率平台。这个证明不要求持仓选择本身连续。

对平方根后验赔率使用 Markov 和 `sqrt(sum a)≤sum sqrt(a)`，独立观测块的 affinity 相乘，得到附件式（21）。Separated 是两个独立时点的组内联合观测；Joint 是一个全维观测和一个空时点，成本均为 d 个标量，不能给 Separated 偷看跨组收益。

## 数值与原创性边界

所有证书使用 QP 原始／对偶界与可行见证重新评价；float64 舍入余量不是严格有向区间算术。高精度 KKT 是独立数值审计，不能以求解器状态替代证书。近零 L* 时不添加正数 floor；不能确认的预算返回开放状态。

有限机会目标、最大可行子系统、IIS/Helly 和 MA 均值最优性均是已有工具。[Park–Lee](https://arxiv.org/html/2606.08895v1) 已将最小不相容集合、多元 Chernoff 与错误指数联系起来；本轮不再主张无预算指数创新。[Multiple Correct Answers](https://arxiv.org/abs/1902.03475) 是多答案信息复杂度的另一直接近邻。新的候选贡献仅限于具体连续组合价格前沿、有限扰动精确公式和后验预算下的部分识别解释，发表优先性仍需独立审阅。
