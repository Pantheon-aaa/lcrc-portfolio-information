**选择“部分采纳 v6”，继续聚焦股票组合优化。** 将原来的三层问题联结起来：

1. **统计信息**：给定历史收益和观测结构，哪些风险模型尚有可信性？哪些模型虽不可识别但决策等价？

## 2. 最重要的机制区分

### 2.1 三类“充分”

- **识别充分**：能辨识具体的协方差模型或观测等价类。
- **决策充分**：给定可信模型集合 `C`，存在一组共同满足 `R_j(w) <= epsilon` 的持仓；即 `Gamma(C) <= epsilon`。模型身份不必完全识别。
- **外部有效**：真正的未来风险结构（或可审查的未来经验代理）确实落在已覆盖的决策范围之内。v5b 的大问题正是在这一步。

### 2.2 两种退化不可混淆

- 如果 `max_j R_j(w_MA) <= epsilon`，则 MA 的内部成功质量已为 1；在全局主目标成功质量最大且以平均 regret 破同分的定义下，A1-B 必然回到 MA。改更复杂的 MILP/割生成不会突破这个数学上限。
- 如果 `Gamma(C) <= epsilon` 但未来经验 regret 不达标，这是**模型内达标与外部风险不一致**，不等于 v6 的数值证书错误。应该检查模型遗漏、历史风险状态变更、oracle 代理噪声和错误的估值数据。

### 2.3 关键 v6 解释修正

旧隐藏曲率构造的非均匀对角扰动会破坏真正的共同最优性；过去零收益主要被远大于 `Gamma` 的 ε 阈值掩盖。v6 的 Bridge 动作包含跨块成对共同观察，因此 Separated 失败并不能证明“必须购买全维 Joint”。

## 3. 候选新理论：风险库外的决策充分性（**待证明原创性与统计校准**）

组合域 `W = {w>=0, 1^T w=1, w_i<=cap}`，定义 `f_Q(w)=.5 w^T Q w`，`R_Q(w)=f_Q(w)-min_{u in W}f_Q(u)`。

对两个风险矩阵 `Q,Q'`，定义决策目标变化幅度：

`d_dec(Q,Q') = max_{w in W} .5 w^T(Q-Q')w - min_{w in W} .5 w^T(Q-Q')w`。

基础引理（可直接形式化证明）：对每个 `w in W`，

`|R_Q(w)-R_Q'(w)| <= d_dec(Q,Q') <= cap * ||Q-Q'||_op`。

理由：`R_Q(w) = max_{u in W}(f_Q(w)-f_Q(u))`，两个最大值的差不超过被加扰动 `h(w)-h(u)` 的统一绝对界；`||w||_2^2 <= cap`。此外，对 `Qbar = sum_j alpha_j Q_j` (`alpha_j>=0,sum alpha=1`)，

`R_Qbar(w) <= sum_j alpha_j R_Qj(w) <= max_j R_Qj(w)`。

所以如果未来真实 `Q*` 满足对某个 `Qbar in conv{Q_j : j in C}` 有 `d_dec(Q*,Qbar) <= rho`，则

`R_Q*(w) <= max_{j in C} R_Qj(w) + rho`。

**可检验候选充分条件**：`Gamma(C) + rho <= epsilon`。这把 v6 的模型内几何判据扩展到模型近似可信、而非真模型必在已知有限集合的情况；v4a 求解器/几何 oracle 可以继续复用。

注意：这是误差传播的条件命题，不自动说明 `rho` 可以从金融时间序列合法校准，更不自动推出分布无关、可选停止或未来市场保护。需要明确平稳/混合/矩条件和时序外推假设，或将实证校准称为经验有效性。

**几何上重要的对照**：当 `Q'=Q+c·11^T` 时，对所有满仓组合 `w` 二次目标增加相同常数，`d_dec=0`，即使矩阵范数误差很大，所有 regret 完全一样。这能展示“不可恢复的协方差信息也可能与决策无关”。与之比较，选择 `v^T1=0` 的 `Q'=Q+s vv^T` 可以产生决策相关误差。必须和 2026 年 GMVP decision geometry、robust satisficing 与 inverse conformal risk control 正面比对：上面这些基本不等式本身不够成为 ICML 独立创新。

## 4. 只做三项按优先级排序的后续实验

### E1：v5b 残留数据与前沿退化诊断（先做，不改变模型）

**假设**：内部 MA 100% 主要源于 ε 相对模型间分歧过宽；未来经验成功差距还有风险库失配和评价估值两个来源。

- 复用 v5b 冻结的 `Q_j,p_j,epsilon,u,wMA`，不得重读未来收益作为优化输入。
- 逐时点输出 `A_t = max_j R_j(wMA)/epsilon`、`Gamma(all)/epsilon`、`L*_p/u`、`model_oracle_L1_spread`、信息熵/ESS、所有模型 regret 与二级模型分歧；分解“阈值饱和、预算不够、数值开放、内部活跃但未来无改善”的占比。
- 与同月份未来经验损失、63日固定组合二阶损失、严格完整标签（207项）和63日估值近似（372项）配对；按年份、指数和数据缺失区分。估值相关异常只列审计，不能擅自填造停牌原因。
- 汇报 `internal_success=1` 时 `future_proxy_failure` 的条件比例及时间块置信区间。当前 372 个可评价窗中未来经验未达标约48.12%，但这不是总体真模型失败概率。
- 同时审计源历史成分、公司行动、停复牌、复权、异常 19.75 倍回报、EM 达迭代上限，严重不合格单元保留未决。

**停止准则**：若主测试绝大部分时点 `A_t<=1`，结束原 F1 下寻找 A1-B 比 MA 更高成功率的工作；继续 E2 检验外部风险误差而不是调小测试 ε。若原数据有不可追溯的重大估值/成分错误，暂停投资账本排名，但机制检查仍可开展。

### E2：纯合成“正确模型→模型失配”的桥接实验（主理论验证）

**假设**：模型内成功不意味着样本外成功，加入一个以决策变化而非全矩阵变化度量的外部误差半径，能控制错误充分性判断，并在盲方向上明显少保守。

- 在固定的 v6 分块/非对称族上新种子生成；`M=6,N=10/12`，分别构造： (a) 正确库 `Q*=Q_j`；(b) 库内 convex combination；(c) 盲扰动 `Q* = Qbar+c 11^T`（PSD）；(d) 决策相关扰动 `Q* = Qbar+s vv^T`、`v^T1=0`、PSD；(e) 随机状态相关扰动，确保协方差 PSD。
- 相同数据/动作/观测成本下比较 MA、A1-B、v6 `Gamma(C)<=epsilon`、增加 `rho` 的 `Gamma(C)+rho<=epsilon`，以及仅 operator norm 校准的通用保守判据。只对“认证”的方法评估错误认证率；到期的 MA/A1-B 不能继承 δ 认证。
- 关键指标：内部成功率、真模型 ε-成功率、假充分率、是否认证、认证成本（同时报告删失）、`rho` 的覆盖率/宽度、盲方向效率提升、随机化最坏模型成功率，以及贪心同目标基线。
- 数据驱动估计 `rho` 与真模型控制分栏。oracle `rho` 用于辨别推导本身是否有解释力，不作为现实可用方法。
- 把已知真模型、留一模型、模型系统性偏移作为三个单独面板，绝不选“使新算法获胜”的误差幅度。

**停止准则**：若只有 oracle `rho` 能给非空证书，而数据校准 `rho` 普遍超过 ε，暂停把此方向定义为可部署算法；可将其转化为信息不够导致无法认证的负结果。若判据只是通用 operator-norm 界的直接改写且对盲方向没有实际节省，避免以此作为论文主定理。

### E3：真实 A 股可信风险库 + 历史校准（在 E1/E2 通过后）

**固定数据**：2011—2026 日频 OHLCV+总收益；指数历史成分已可用但仍需核验日期；未来收入和分红以可信总收益链核对。主数据只读原版本；新补数据增加版本与哈希。

- 主股票池沿用历史时点沪深300/500，每域三个固定50股面板；先在开发年份测试 N=20 与50，最终 N=100 扩展只有在前两步明确显示可计算现象后执行。
- 风险库：旧 F1（126/252/504 × 4收缩）作为固定对照；额外预设两类有经济机制的风险表示，例如市场/行业或 PCA 因子协方差，以及完整同步时间块 bootstrap 或短长波动状态组合。行业标签缺失时只用历史价格截面构造 PCA，不能事后回填行业。
- 风险矩阵 PSD、数值收敛、正则化强度、预序列 NLL、未来固定组合二阶损失、风险模型间最优权重差、`Gamma/epsilon` 必须分开汇报。风险库不得按测试胜负排序。
- `epsilon` 不在已读过的 2020—2025 测试上重新调小；新的校准口径先在开发数据确定，并注明这些历史年份也在旧研究中已被反复查看，不能声称完全未触碰的独立确认。
- 探索外部模型误差的经验校准 `rho`。必须先给出清晰的数据生成/滚动稳定性假设、重叠标签处理及适当时间块推断；在无法证明覆盖时仅报告经验可靠度，不声称分布无关证书。
- Primary endpoints：冻结 63 日固定组合二阶损失、按月配对差、未来经验 ε-近优达标（代理）、内部活跃率、模型校准失败率/误差半径、最差时间段表现；Secondary：63/126日评价敏感性、p95未来损失、换手、真实可核验交易成本和净值。若六面板无法形成完整可信账本，收益/Sharpe留为未决。
- 比较：MA、A1-B、Budget-Greedy、EM shrink GMV、因子 shrink GMV、等权；可选 v6 认证/停机层，后者不得冒称现实主动购买新独立股票日收益。

**停止准则**：如果更可信的风险库仍使 `Gamma/epsilon` 极低且 MA 内部成功=1，重点改为“为何风险库不足以评价未来决策”，不再强调 A1-B 新算法增益；若更换风险库确实激活 A1-B，但未改善真实固定暴露损失，则退出“真实绩效优势”主张，考虑只写机制理论。只有在冻结风险模型、阈值、数据资格之后出现跨指数且跨时间段的一致配对效果，才进入正式大规模回测。

## 6. 论文创新与最近邻审查
