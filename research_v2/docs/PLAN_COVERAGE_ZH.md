# 计划覆盖与尚未成立的结论

本表区分实际执行、有限诊断和仍未完成的研究结论。逐算法及超参数的次数以 ALGORITHM_CATALOG 和 algorithm_coverage.json 为准；清单完整性以 delivery_validation.json 为准。

| 计划部分 | 实际交付 | 范围与限制 |
|---|---|---|
| A/B/C/H 全部方向 | 44 个固定方法/参数规格，各 24 个开发实例；另补做两项 beta=0.5 Blend | 包含图片中的 B-Max、所有四种 H 顺序变体及条件版本；没有把不连续启发式冒称凸目标 |
| 同信息强基线 | MA、独立开发边缘似然拟合的 EB；另有等权、EM、MLE、旧 LCRC 和特权先验审计 | 特权先验是已知有限测试网格分布，不是连续先验积分的精确 oracle；EM 为描述性对照 |
| G1 | 3 风险族 × 8 点 × 10 重复 = 240 实例 | 四种权重汇总针对有限真值网格；旧匹配先验实验保留在 v1，未混合统计 |
| G2 | 3 风险族 × 8 点 × 8 信息预算 × 10 重复 = 1,920 实例 | 主实验 p=3、20 资产，结构给定；m=0 条件后验恒等式通过检查 |
| 原独立确认 | 新风险族与种子、每点 30 重复，共 6,480 实例 × 8 方法 | 没有因为排名不好而追加有利种子；只有三个家族，跨家族推断仍有限 |
| 选择准则修订 | Blend 开发 48 行；原 G1/G2 补充 8,640 行；复用测试面板补充 12,960 行 | 原选择准则过严；修复在查看原确认后发生，因此这些是探索性补充，不是新的确认 |
| G3 | d=20、50；六种环境，各三条路径、12 个评价窗；每维 216 窗口 × 9 方法 | 算法使用过去数据学习场景；未给生成器真参数；区间按路径，而非窗口独立计算；没有将原族 EB 偷换到 bootstrap 空间 |
| 局部多资产边界 | d=6、20，固定种子与尺度；6,720 条结构记录及 600 条数据后验记录 | 人工概率实验与数据驱动概率实验分开，不合并为算法排名证据 |
| 信息下界嵌入 | 9,600 条同协方差收益/决策子类记录；正定、完整 QP、mask、KL 核验 | 与理论定理对应的有限两模型子类；不是一般连续风险族的最优率 |
| 场景与后验精度 | 128/256/512、三个 scramble、1024 参考；触发后增加 4096 参考与连续 MCMC 审计 | ESS 不代替精度证明；B-Max 主结果只是有限场景最大值；连续尾部全局误差未被严格界定 |
| 消融 | 固定/EB 先验、固定概率 floor、后验抽样 Top-k 收敛、regret/absolute、外层 plug-in、条件 reference/posterior | 小面板为诊断，不声称每项模块在所有环境都必要；结构实验另比较消失 floor |
| 信息几何 | 旋转坐标观测核、Fisher 与 Schur 补、数据驱动分箱分组 | 分箱明确标为近似消融，不冒充真正嵌套条件积分；大规模自适应分组尚未完成 |
| 扩展 | p=5 的 72 行精度诊断；小型共同 L1 交易成本测试 | 未作五维全面确认或交易策略成本回测 |
| 求解正确性 | Gate-V2、独立 CVXPY/Clarabel、QP 上下界、概率与组质量、复制不变性、反例 | float64 数值保证，不是区间算术证明；开放 gap 和启发式无全局界如实记录 |
| CPU | 十实例六方法冷启动/缓存审计；运行账本、八进程记录、单线程 BLAS | 24 小时是预算上限；不为了用满预算而增加看过结果后的搜索。短暂交互检查未全部计时 |
| 理论 | 硬锥/软惩罚/消失极限；有限条件扩展；熵温度比较；高斯证据界；嵌入检验下界与可达性；联合质量稳定性 | 完整证明针对明确条件；一般同时内外层衰减、连续 nuisance、锐常数和创新优先性仍开放 |
| 论文与公开发布 | 英文理论 Markdown、可编辑 TeX、编译 PDF、中文解释与报告 | 按本轮要求未直接重写整篇 ICML 稿；未公开推送；v1 未覆盖 |
| 真实 A 股 | REAL_DATA_PROTOCOL.md | 本轮未读取数据执行回测，不声称已观察到总体 covariance regret |

尚不成立的三项关键宣称：条件尾部具有稳定的独特算法优势；当前方法在一般连续族上统计最优；本轮有限场景输出附带频率学 95% 近优证书。没有这些结论并不使结构实验无效，但决定了下一轮应先推进精度与理论，而不是直接宣布新 SOTA。

完整方法记录中，无全局下界的启发式采用 Python JSON 的 NaN 表示未知数值，不能读作零或有效 gap；标准严格 JSON 消费者应先将非有限数值转换为 null。该格式细节不影响提供的 Python 复现与汇总程序。
