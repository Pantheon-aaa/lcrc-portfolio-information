# 不完整风险信息下的组合决策：第二轮详细研究报告

研究日期：2026-10-08。本文是供独立审阅的研究记录，包含算法、实验、证明思路、负面结果和实现修订；不是已经完成同行评审的论文，也不是 SOTA 声明。原始结果在本轮结束后整理，未根据报告叙事重新选择种子。

## 1. 先给出本轮结论

本轮实现了 44 个固定方法/超参数规格，并补做两项 Blend，共 46 个规格。完成 G1、G2、G3、边界机制和精度审计。主要开发、筛查、原确认及补充比较合计 **117,312 条“实例×方法”记录**；这不是 117,312 个独立数据集，其中多种算法共享同一实例。

结论分为三个层次。

1. **算法优势尚未确认。** 原冻结确认集的 6,480 个新实例中，没有入围方法稳定改善同信息 Model Averaging（MA）的平均 regret。条件尾部在 G2 的平均与最坏测试点之间存在描述性权衡，但全局尾部几乎获得同样结果。不能据此宣称条件化带来独特优势。
2. **理论机制值得保留。** 在有限模型、共同基准最优解、固定多面体约束和统一强凸条件下，可以证明：坏模型概率与局部决策尺度的相对速度决定硬约束、软惩罚或影响消失。进一步在一个同协方差生成收益并定义风险的多资产子类中，建立了共同观察数的匹配阶必要性与可达性。
3. **当前主要障碍不只是优化。** 大部分凸问题已满足数值 gap；更棘手的是连续后验积分、场景覆盖，以及 G3 中近似场景后验过度集中。小于这些敏感性的性能差，不能作为可靠算法贡献。

建议把下一轮主问题收敛为：**需要多少可区分模型的证据，才能解除模型歧义对某个持仓方向的限制？** 尚不建议把论文主线写成“条件 CVaR 普遍优于模型平均”。

## 3. 本轮研究的问题与评价对象

### 3.1 不再只问“协方差估得准不准”

同一份不完整历史数据可能支持多个协方差模型。对每个模型，最优组合可能不同；我们需要在这些模型尚未被排除时选择同一个组合。

本轮共享损失为

$$f_j(w)=\tfrac12w^\top Q_jw-\mu_j^\top w+g(w),\qquad
V_j=\min_{u\in\mathcal W}f_j(u),\qquad R_j(w)=f_j(w)-V_j.$$

主性能实验采用零均值 GMV：$\mu_j=0$，长仓、权重和为一、单资产上限 0.2，20 资产；G3 另有 50 资产。共同 $L_1$ 交易成本只做小型机制检查，没有展开成本策略回测。

必须区分三个量：参考质量 $b_j$、数据后的质量 $p_j\propto b_j\exp(\ell_j)$、优化中不利重加权 $q_j$。前两者描述我们如何表示与学习模型，第三个描述决策者对坏情形赋予多大权重。直接平均各模型的最优持仓一般不同于求解平均目标，因此代码平均的是目标矩阵，再解 QP。

### 3.2 三种“尾部”不能混淆

- **优化目标中的尾部：**对同一持仓，在不同候选风险模型下的 regret 取上尾。
- **跨数据重复的尾部：**固定方法多次看到不同数据后，其真实 regret 的 90%/95% 分位。
- **固定参数风险曲面的最坏测试点：**先对同一参数和信息设置下的重复取平均，再取测试网格上的最大值。

它们也都不是“最差交易日收益”的时间序列 CVaR。主指标是合成总体协方差下的 regret；真实 A 股上无法直接观察该总体量，本轮没有运行 A 股回测。

数值统一除以开发阶段固定的风险单位

$$u=0.03827751737525126.$$

下文写“1.80061%u”是 regret 等于 $0.0180061u$，不是投资收益率下降 1.8%。写“相对 MA 增加 3.2%”又是另一种比例，两种口径会明确区分。

## 4. 实现了哪些算法，差别在哪里

全部规格和次数见 [算法目录](docs/ALGORITHM_CATALOG.md)。以下解释目标及用途，而不是把每个参数值当成独立创新。

### 4.1 A 类：全局平均与全局尾部

核心概率尾部为

$$T_\rho(R;p)=\min_z\left[z+\rho^{-1}\sum_jp_j(R_j-z)_+\right]
=\max_{q\in\Delta,\ q_j\le p_j/\rho}\sum_jq_jR_j.$$

$\rho$ 是最坏模型所占的概率质量。$\rho=1$ 退化为均值；小 $\rho$ 更关注坏情形，但不等于置信水平。

| 方法 | 实现与作用 |
|---|---|
| A-Mean / MA | 后验平均目标；等价于后验均值风险矩阵的 QP，是主要强基线 |
| A-ATK | 当前 regret 最大的 $k=\lceil\rho M\rceil$ 个场景等权平均 |
| A-Tail-P | 后验概率尾部，$\rho=0.25,0.5$ |
| A-Tail-U | 参考质量尾部，移除似然更新；重要性节点质量不均匀时不等于等权 Top-k |
| A-Max | 所有给定场景的最大 regret |
| A-Blend | 均值与尾部各占 0.5；补充开发后运行 |
| A-Absolute | 尾部中的 regret 换成绝对风险，检查 oracle 常数的作用 |

均值目标可以删除与持仓无关的 $V_j$；尾部或最大目标中删除它们，会改变场景排序或不利权重，得到另一个问题。

### 4.2 B 类：保护强信息部分的后验边际

参数写成 $(\phi,\eta)$。外层节点为 $\phi_s$，内层是对应的 $\eta_{sj}$。从完整联合似然构造 $P_{sj}$ 后，计算

$$\alpha_s=\sum_jP_{sj},\qquad p_{j|s}=P_{sj}/\alpha_s.$$

B-Tail-P 优化

$$\min_w\sum_s\alpha_sT_\rho(R_{s\cdot}(w);p_{\cdot|s}).$$

其对手可以在每组内部改变概率，但每组总质量必须保持 $\alpha_s$。B-Max 对应用户图片：外层 Bayes 平均、内层条件最大 regret。没有把期望、最大化和选择持仓的顺序交换。

还实现 B-Mean、B-Tail-U、B-ATK、B-Blend 以及外层 plug-in。B-Plugin 取离散后验外层质量最大的节点，在该组内解尾部问题；不是连续 MAP 的精确算法。

固定持仓下，均值不大于条件尾部，条件尾部不大于全局尾部，全局尾部不大于最大值。**不同算法各自选出的持仓，没有相同的真实 regret 顺序。**

当数据不区分 $\eta$ 时，条件后验必须等于条件先验。此时正确参考测度下的 B-Tail-P 与 B-Tail-U 一致。主实验的分组来自已给定的模型和观测结构，不由真参数标签决定。

### 4.3 C 类：对坏场景施加证据代价

令 $d_j=\max_l\ell_l-\ell_j$。

| 方法 | 目标或约束 |
|---|---|
| C-LP-Max | $\max_j(R_j-\lambda d_j)$ |
| C-LP-Tail | 对 $R-\lambda d$ 取参考质量尾部 |
| C-Budget | 在尾部权重集合上再加 $\sum q_jd_j\le c$ |
| C-Soft | $\tau\log\sum_jp_j\exp(R_j/\tau)$ |
| C-Soft-Cond | 每组内熵平滑，外层固定 $\alpha_s$ 平均 |
| C-LR | 参考质量下的反向 KL 球：$D_{KL}(b\Vert q)\le r$ |

$\lambda/u,\tau/u,r$ 分别使用固定网格 0.01、0.1、1。C-Budget 先求最小可行证据预算，再取其与参考平均证据代价之间的 25%、50%、100% 位置。没有把空权重集合当成方法失败，也没有同时搜索似然幂次、温度、尾部比例和混合比例。

C-LR 的参考质量不是观测频数，因此它是有限场景方法迁移，不能直接继承原始 likelihood robust optimization 的统计校准解释。固定场景之后，参数似然不全局凹并不妨碍持仓目标为凸；场景推断自身则仍可能需要近似或多起点。

### 4.4 H 类：保留用户提出的排序顺序变体

实现先按 regret 取 Top-k 再归一化后验、对 $p_jR_j$ 取 Top-k、先过滤到累计后验 0.95 再等权 Top-k、从后验抽样再等权 Top-k；四者均有条件版本。

排序随候选持仓重新计算，未在初始组合处固定。后验抽样后没有再次乘似然。H-pR 是固定概率下的凸 Top-k 目标，但依赖场景表示；H-RankThenP 可能不连续，使用等权、MA、全局尾部、B-Max 四个固定起点的无导数搜索，不声称全局最优。

本轮复现了三个场景的跳跃反例，也验证复制场景并平分质量不会改变概率尾部，却可以改变计数类规则。因此“更多场景让结果变好”有时只是目标被改变，不能直接称作数值收敛。

## 5. 从缺失数据到持仓：实际计算链条

### 5.1 完整 mask 似然

每条记录仅使用实际观测子集 $S_i$ 的高斯密度，按相同 mask 缓存散布矩阵和分解；没有用两两似然替代联合密度。对于零均值候选协方差，去掉共同常数后

$$\ell_j=-\tfrac12\sum_i\{\log\det Q_{j,S_iS_i}+y_{i,S_i}^\top Q_{j,S_iS_i}^{-1}y_{i,S_i}\}.$$

独立模型的混合证据在整个数据集似然层面用 log-sum-exp 计算，而不是让每条观测自由选择另一个模型。源代码复用 v1 的 `MaskLikelihood`，新代码负责场景和条件质量。

### 5.2 场景不是任意散点分箱

G1 使用 128 个嵌套节点，8 个外层 ×16 个内层。G2 主结果采用 256 节点，16×16。精度审计比较 128/256/512、三个 scramble，后续增加 1024 和 4096 参考。

初始 G2 固定网格出现低 ESS 和 scramble 敏感性，触发预定的重要性积分路线：

1. 只用观测数据拟合外层提议；组内复合似然只用于拟合提议，不是最后的后验似然。
2. 提议保留 25% 均匀成分，避免完全丢失参数域支持。
3. 外层通过混合分布 CDF 的 Gauss–Legendre 积分，内层使用 Sobol 与截断正态/均匀的确定性混合。
4. 明确乘先验密度/提议密度和积分权重，再用完整 mask 似然更新一次。

同信息方法共享场景和参考测度。加密不改变目标先验。未添加永久均匀后验 floor；固定 floor 只作为有标记的消融。熵目标从对数质量作 log-sum-exp，不在指数倾斜前删除低概率节点。

这不是连续域覆盖证书。高 ESS 也不能证明没有漏掉模式。数据驱动分箱的 Fisher 分组仅作探索性消融，未冒充真正的嵌套条件积分。

### 5.3 求解与上下界

对凸权重集合 $\mathcal U$，使用

$$\max_{q\in\mathcal U}\left[V\left(\sum_jq_jQ_j,\sum_jq_j\mu_j\right)-\sum_jq_jV_j\right].$$

内层是普通约束 QP；尾部/max 另有独立 epigraph 参考。大场景加入直接 Clarabel 锥实现以减少建模开销，其结果仍需通过相同的数值界验收。熵和反向 KL 使用对应支持函数与梯度；不连续方法单独处理。

若场景 oracle 只有 $V_{j,L}\le V_j\le V_{j,U}$，可行持仓的 regret **上界**必须减去 $V_{j,L}$；对偶 **下界**则减去 $\sum q_jV_{j,U}$。反过来会产生虚假小 regret。

默认 float64、单线程 BLAS，普通可行残差目标约 $10^{-8}$，聚合 gap 目标 $10^{-6}u$，单次先设 60 秒上限。原始目标、数值上下界、真实评估 regret 和统计保证分开存储。新尾部目标没有被写进旧的 95% 风险证书字段。

这些界使用 float64 修复和余量，不是有向舍入的形式化证书。启发式未知全局下界留空/非有限，不填零。原始 JSONL 保留 Python JSON 的 NaN 表示，严格 JSON 消费者需转成 null。

### 5.4 数据权限和追踪

`solve_center` 接收场景、后验、方法规格和风险单位，不接收测试真协方差。生成器和评估器持有真值；调参只读取独立未来实现损失。结果包含真值是为了事后审计，并不意味着算法读取它。

冻结清单包含阶段、风险族、参数点、信息量、重复号和确定性种子。修复后沿用同一清单，不替换不利种子。场景 oracle 缓存检查风险矩阵、均值、约束、共同惩罚与原持仓的签名，防止改变 QP 后误用缓存。

## 6. 数据生成、筛选和确认具体如何安排

### 6.1 开发集与先验

另用 24 个开发数据集定义 $u$：等权持仓在独立未来 128 行收益上的半二阶损失取中位数。EB 通过开发数据的边缘似然学习四种预设先验的混合权重，不使用开发真参数标签。拟合质量约为：均匀 $10^{-8}$、中心 0.6411、边界双峰 0.1459、偏斜 0.2129。测试时不重新拟合。

全变体开发面板也是 24 个固定实例，覆盖两个生成器和三个风险族。这里有一项需审阅的实际限制：面板按循环规则生成，**不是完整析因设计**；G1 配到 $n=256,m\in\{0,16\}$，G2 配到 $n=64,m\in\{4,64\}$。因此开发选择未直接覆盖 G2 的全部信息组合。系统筛查与确认则覆盖完整 G2 网格。这一限制没有在结果出来后通过换开发种子掩盖。

### 6.2 G1：固定参数风险曲面

三参数仿射协方差族：一个可观测对角异方差方向，加两个跨块低秩相关方向。20 资产，对角基准在约 0.65–2.8 间变化，扰动系数固定并保证正定。

每族八个真值：一个中心点、两个相反跨组边界点、五个预先生成的 Sobol 内部点。三个风险族、每点十次重复，固定 $n_B=256,m=16$，共 240 实例。风险先按点估计，再用均匀、中心、边界双峰和偏斜质量汇总。后者是有限网格加权，不等于连续分布积分。

特权 oracle-prior 对照知道有限测试网格及其分布，只作参照，不混入同信息算法胜负。旧的匹配均匀先验实验仍保留在 v1。

### 6.3 G2：组内易学、跨组信息稀缺

两个各十资产的块，构造

$$Q(\phi,\eta)=\begin{pmatrix}A(\phi)&A(\phi)^{1/2}C(\eta)B(\phi)^{1/2}\\B(\phi)^{1/2}C(\eta)^\top A(\phi)^{1/2}&B(\phi)\end{pmatrix}.$$

实际首版 $A,B$ 是正对角矩阵，按有界对数尺度随 $\phi$ 变化；不是一般稠密块风险。$C=U\operatorname{diag}(0.8\eta)V^\top$，$U,V$ 列正交，故谱范数不超过 0.8，结构保证正定。使用对称与非对称方向族，主参数维数三；五参数仅做额外诊断。

每个数据成本块有两种形式：一次联合观测两组，或两个独立时点分别观察一组。两者都观察 20 个标量。代码中未观测的行/列保留为 NaN。因此改变 $m$ 不改变 $20n_B$ 的观测标量预算，却改变联合信息。

网格为 $n_B\in\{64,256\}$、$m\in\{0,4,16,64\}$。三族、八点、八信息组合、十重复，共 1,920 实例。$m=0$ 时跨组参数严格不可识别；增大组内历史不能消除这部分歧义。这个非仿射族没有调用旧仿射顶点连续覆盖证书。

### 6.4 原独立确认

开发完成后冻结八种方法：MA、EB、两个平均初选、两个条件尾部机制候选、B-Max 和全局尾部 0.5。确认换用新的风险族和数据种子，每点 30 次重复，G1 720 实例、G2 5,760 实例，共 6,480；八方法合计 51,840 行。

配对比较在相同数据实例上进行。报告风险族均值上的 t 区间及 Holm 校正，并提供按风险族、固定参数/信息层、成对重复重采样的层级 bootstrap。只有三个独立风险族，不能把几千实例当成几千个独立模型族，也不能从非显著推断方法等效。

### 6.5 G3：未知名义结构与时间变化

以三个因子的收益过程生成市场，先 20 资产，再 50 资产。六环境分别为完整平稳高斯、不均匀历史、相关性状态变化、波动变化、保协方差标准化 $t_6$、收益相关缺失。每环境三条路径，每路径十二个不重叠未来评价窗；每个窗口回看 252 日，评价未来 21 日。

算法不知道真实载荷或生成器风险方向。过去前 126 日估计名义结构及外层组内 bootstrap 风险，内层扰动估计的跨组奇异方向；过去后 126 日对场景评分。这个实现在内层只扰动前两个跨组奇异值，因此对复杂风险变化的覆盖有限。质量明确称为近似 bootstrap 参考，不是精确生成模型后验。

超参数从既有开发步骤冻结；没有在 G3 的未来 21 日评价窗口重新选参。原参数族 EB 没有强行移植到不同的 bootstrap 空间。未来条件风险 oracle 使用生成器的条件期望协方差目标，不用未来实现冲击决定持仓。标准化 $t_6$ 与收益相关缺失都是压力测试，不继承高斯似然保证。

### 7.2 筛选准则修复后的探索性补充

原差情形筛选错误地要求 $\max_g E_g[L_A-L_{MA}]<0$，即每组都改善；预期准则应是 $\max_g E_gL_A-\max_gE_gL_{MA}<0$。前者使付出平均代价换取最坏组改善的 Blend 触发条件无法成立。

Blend 与所有补充结果见 [补充筛查表](results/repair_screen_summary.csv)及 [补充配对表](results/supplement_exploratory_paired.csv)。未为这两个新增候选补造新的 G3 或精度确认，因此本轮不授予最终有效算法资格。

## 8. 精度审计和失败记录

### 8.1 不能把求解精确等同于统计积分精确

核心 gate 核对均值恒等式、Top-k/CVaR 等价、固定持仓顺序、场景复制、无信息条件后验、旋转观测核、上下界方向、固定组边际、独立求解器和数值可行性。gate 通过表示实现与指定离散问题相符，不表示连续模型族已被足够准确地积分。

三个 scramble 的审计暴露敏感性后，增加 4096 节点参考。下表为六个审计实例中，256 节点持仓在加密目标上的最大超额，单位是**原始目标单位**，不是 %u。

| 方法 | 最大参考目标超额 |
|---|---:|
| MA | 2.4355e-5 |
| 全局尾部 0.5 | 6.8650e-5 |
| 条件尾部 0.5 | 7.0068e-5 |
| 条件尾部 0.25 | 1.1952e-4 |
| B-Max | 1.6440e-3 |

这些敏感性远大于若干方法间的平均差，因此后者不能可靠解释为性能优势。表中参考也不是严格的连续积分误差上界。

G2 固定外层后，协方差对隐藏参数仿射，regret 对隐藏参数凸，内层最大值可在参数盒角点取得。B-Max 的加密审计使用全部角点，但主性能结果仍是有限场景 B-Max；两者不能混称精确连续 minimax。

另对三个高信息边界实例运行两条连续参数 MCMC 链，经典 split-Rhat 最大约 1.0046，最小 ESS 约 695；MA 的持仓和目标得到额外交叉检查。有限链诊断既不证明所有模式已找到，也不证明条件尾部积分精度。

### 8.2 启发式与开放 gap

H-RankThenP 四起点目标差最大约 0.245u，条件版约 0.472u；数值不稳定足以阻止扩大为确认候选，而不仅是形式上“没有凸性证明”。

主要 117,312 行没有未处理异常或缺失配对，但“有结果”不等于“达到精度”：开发 C-LP-Tail:1.0 有四条开放 gap，补充 C-LP-Max:0.01 有两条；其余主要凸结果符合相应验收。两条补充 gap 约为 $7.0\times10^{-6}u$、$9.6\times10^{-6}u$，高于目标 $10^{-6}u$，没有删除或重标为成功。

## 9. 理论具体推进到哪里

完整英文陈述与证明见 [THEORY_NOTES](docs/THEORY_NOTES.md)，可阅读 [PDF](output/pdf/THEORY_NOTES.pdf)。以下说明逻辑，不以数值图代替证明。

### 9.1 固定正概率为何也能产生硬边界

在共同基准解 $w_0$ 附近，对局部动作 $w_0+tv$ 展开：

$$R_{j,t}(w_0+tv)=t a_j(v)+t^2h_j(v)+O(t^3),\quad a_j(v)\ge0,\quad C_j=\{v:a_j(v)=0\}.$$

$a_j$ 描述沿边界方向移动的一阶代价，$h_j$ 包含二阶曲率、扰动和模型 oracle 改善。模型可以有不同曲率、不同临界锥。

若坏模型概率保持正值，它的 $t$ 级损失会压过 $t^2$ 级收益，所以追求 $O(t^2)$ 总损失的方向必须落在这些模型的共同临界锥内。普通 Bayes 平均也有这个现象，不能仅把 max 换成 mean 就宣称边界限制消失。

### 9.2 概率尺度定理

设 $p_j(t)$ 收敛且 $p_j(t)/t$ 有扩展极限。非消失模型构成 $B$，比 $t$ 衰减慢的构成 $H$，$p_j(t)/t\to c_j\in(0,\infty)$ 的构成 $S$。固定 $\rho>0$ 时，归一化最优值收敛到

$$\min_{v\in\cap_{j\in H}C_j}\left[
T_\rho(\{h_j(v)\}_{j\in B};p_B^0)+\rho^{-1}\sum_{j\in S}c_ja_j(v)\right].$$

三个区域的直觉是：$p_t\gg t$ 留下硬限制，$p_t\asymp t$ 留下软惩罚，$p_t=o(t)$ 不再影响二阶首项。

证明依次使用：基准持仓给出 $O(t^2)$ 上界；非消失概率和强凸性使最优位移局部化为 $O(t)$；多面体结构给统一展开；均值下界排除不在硬锥中的方向；阈值形式处理消失概率；固定可行方向构造恢复序列；强凸性推出最优方向唯一和收敛。$\rho=1$ 单独按均值处理，没有错误地沿用分位阈值论证。

这里得到的是极限，若没有额外概率收敛率，不能自动写成统一的 $O(t^3)$ 余项。

### 9.3 条件化与熵平滑不是机械套用

外层组质量趋于正数时，可以把各组的极限加权，所有硬锥约束仍需作用于同一个持仓方向。若外层质量本身以 $t$ 量级消失、而条件分布固定，软项是该组**一阶代价的条件尾部**，不是简单把全局公式逐项相加。一般同时内外层变化仍未闭合。

固定正温度的熵平滑局部退化为均值型；温度 $\tau\asymp t^2$ 时，多项式小概率模型仍可能形成硬边界。相关尺度包含 $\tau\log(1/p_j)$ 与一阶损失的比较，不能仅依据 $\tau/t^2$ 判断。有限尺度图也不能冒充已经观察到所有渐近温度区间。

### 9.4 一个可解释的持仓公式

两模型一维例子给出

$$\frac{x_t^*}{t}\longrightarrow\frac{[a-cs/\rho]_+}{h}.$$

$a$ 是买入信号，$s$ 是坏模型的一阶边际代价，$h$ 是曲率，$c$ 来自 $p_t/t$。它具体说明“证据不足需要扣掉多少买入信号”。有限 $t$ 下，某些尾部规则停在 $O(t^2)$ 折点而不是严格零持仓；笔记给出精确有限公式，避免把非常小的持仓误称为完全禁止交易。

### 9.5 从共同观察到信息下界

完整 mask 高斯似然给出带先验赔率的 affinity/Chernoff 概率界，先控制错误模型后验，再连接边界响应；没有把 $m\,KL$ 的期望当作随机样本路径等式。转成期望 regret 时，另行控制小概率错误事件的贡献。

Theorem 6 构造两个各至少五资产的组，同一组内风险在两模型下完全一样，跨组风险不同；相同协方差同时用于生成高斯收益和定义组合损失。任何非均匀组内持仓都增加共同非负代价，因此可严格约化为第二组的总持仓，但定理不要求算法先验对称。

若要求模型一的期望 regret 为 $o(t^2)$、模型二为 $O(t^2)$，可以把决策转成一个检验，得到

$$m(t)K(t)\ge (1-o(1))\log(1/t)-O(1).$$

在这个子类 $K(t)$ 趋于正常数，后验 regret CVaR 用充分大的 $m=C\log(1/t)$ 也能达到要求。因此匹配的是**共同观察量的阶**，不是最优常数。两个候选模型及 $t$ 索引的问题给定，未知的是模型身份；不能外推成一般未知连续协方差族的最优率。

### 9.6 成熟工具与可能贡献的边界

Top-k、CVaR、后验风险优化、部分识别条件 minimax、likelihood robustness、TERM、Bayesian DRO 和相对稳健组合都有直接近邻。相关原始文献与阅读深度见 [近邻对照](docs/LITERATURE_AND_CLAIMS.md)。

当前可能值得发展的增量是：概率尺度与异质临界锥的相互作用、条件外层质量消失的正确极限、熵与 CVaR 对稀有坏模型的不同边界响应，以及同协方差观察/决策子类的信息要求。仍需专门核查一般二阶 epi 微分和随机规划敏感性理论是否已直接包含这些结论。独立推导不等于已证明创新优先性。
