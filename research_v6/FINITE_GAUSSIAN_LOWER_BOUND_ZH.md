# 有限高斯族的成本下界：独立核查草稿

状态：有限族、固定ε、正观测成本条件下的证明草稿已逐步核查；尚未经外部审阅。它是多正确答案信息下界在本设置中的具体推导，不作为独立原创理论宣传。本轮采样启发式的渐近最优性**没有**因此得到证明。

## 1. 假设与结论

候选族Θ、动作集A均有限。动作a的成本c_a>0；一次观察由已知正定高斯子矩阵密度的有限乘积组成，动作在观察前可预测，各次新观察条件独立。内部随机化的分布不依赖未知真模型。约束W与阈值ε固定，不随δ改变。所有模型的ε-好集合非空。

考虑一族对每个θ都正确的程序：输出ε-坏组合或不返回组合的概率不超过δ。记τ为返回时刻，C_τ=Σ_{s≤τ}c_{a_s}；不返回时记∞。设兼容集合G满足Γ(G)≤ε，D_c与T_c定义同执行规范。

当0<D_c(θ)<∞时：

`liminf_{δ→0} E_θ[C_τ]/log(1/δ) ≥ 1/D_c(θ)`。

更强地，对任意η∈(0,1)，`P_θ(C_τ≤(1−η)log(1/δ)/D_c(θ))→0`。这是渐近结论，不是把log(1/δ)/D直接当作每个有限δ的数值下界。

## 2. 将连续输出划为有限答案事件

任意输出w对应成功集合S(w)。若S非空，按固定编号把S扩张为某个极大兼容集合G；空S放入失败事件。在θ下，概率至少1−δ的输出满足θ∈S⊆G。

对任何λ∉G，事件“输出被映射到G”必然意味着λ下输出失败：即使G的见证不是实际输出，实际成功集合S仍包含于G。因此该事件在P_λ下概率至多δ。这是后续变化测度需要的性质。

极大集合数至多2^M，虽可能指数大，但在δ→0时是固定常数。这里没有使用Helly来声称答案数量为多项式。

## 3. 自适应高斯似然比的集中

固定θ、λ。令Z_t=log(p_θ^{a_t}(X_t)/p_λ^{a_t}(X_t))，条件均值为KL_{a_t}(θ,λ)。同一自适应策略的动作概率在两模型的路径似然比中抵消。

对一个高斯mask，令B=Σ_θ^{1/2}Σ_λ^{-1}Σ_θ^{1/2}−I，Z−E_θZ=(gᵀBg−tr B)/2，其中g标准高斯。其中心化对数矩母函数为

`log E exp(s(Z−EZ)) = −s tr(B)/2 −(1/2)log det(I−sB)`。

在|s|·||B||<1的邻域内有限且为O(s²)。独立mask乘积将对数矩母函数相加。由于模型和动作有限，可以统一选择s_0>0、v<∞，使所有这些中心化增量在|s|≤s_0内满足条件对数矩母函数≤v s²。

所以对于最多n次自适应观察，指数超鞅给出

`P_θ(max_{t≤n} Σ_{s≤t}[Z_s−KL_{a_s}(θ,λ)] ≥ h) ≤ exp(−s h+n v s²)`。

令b=log(1/δ)，成本不超过Tb的路径，其观察次数最多Tb/c_min。取h为固定正数乘b、取足够小的固定s，右侧为exp(−κb)。对有限λ求并集仍趋于零。这一步提供协方差高斯似然二次型所需的集中，避免直接照搬单均值子高斯假设。

## 4. 低成本路径必留下难以排除的模型

令B_δ=(1−η)b/D_c(θ)。在任一C_τ≤B_δ且映射到含θ的G的路径上，若C_τ>0，定义x_a=N_a(τ)/C_τ，则Σc_ax_a=1。由D_c的定义，存在λ∉G满足

`Σ_a N_a(τ) KL_a(θ,λ) ≤ C_τ D_c(θ) ≤ (1−η)b`。

C_τ=0时同样有零累积信息。按固定编号选择这样一个λ，即可把低成本成功事件划成有限个(G,λ)事件。

除去第3节概率趋零的集中坏事件，停止时路径log似然比不超过(1−η/2)b。对其中每个E_{G,λ}，停止路径变化测度给出

`P_θ(E_{G,λ}) ≤ exp((1−η/2)b) P_λ(E_{G,λ}) ≤ δ^(η/2)`。

最后一步使用λ∉G时实际输出必坏，以及程序在λ下的δ正确性。对有限G、λ求和，再加上θ下本来的失败概率δ和集中坏事件，得到低成本停止概率趋零。由非负成本的截断下界，推出期望成本结论。证明不假设算法的采样比例收敛。

## 5. 与部分识别类的关系

令E(θ)为所有允许动作下与θ观测等价的模型类。

- 若Γ(E)>ε，任何含θ的兼容G都遗漏至少一个λ∈E；该λ的全部动作KL为零，故D_c(θ)=0。δ足够小时随机化也不能规避统一正确性；其有限δ极限由随机兼容集合LP决定。
- 若Γ(E)≤ε，则可将E扩张为兼容G。对每个λ∉G，它不属于E，至少一个允许动作有正KL。对全部动作分配正的成本份额，在有限外部模型上取得严格正的最小信息率，故D_c>0；若全族兼容，则D_c=∞、T_c=0。

因此“Γ(E)>ε与无穷特征成本对应”在这个有限、已知、固定ε的定义下可直接核验。它不等价于“对所有固定δ随机化决策都不可能”，也不等价于“每个有限预算实验必须观察到零认证”。

## 6. 为什么这还不能证明当前采样法最优

一个知道θ的固定最优分配可为外部备择提供相应信息增长率，但实际方法不知道θ；滞后选择、冲突限制、近并列答案及数值开放都要另行分析。完整KL分配也不能因使用了同一个LP就自动获得sticky TaS的定理。

此外，本轮采用历史越界永久排除的置信集。若置信集变空，规则返回未认证；在罕见覆盖失败路径上，**到成功认证的时间可以为∞**。所以即使高概率认证成本接近T_c log(1/δ)，也不能直接推出无条件期望认证时间渐近最优。实验明确采用共同预算下的截断成本，并同时报告认证率与错误率；预算到期的A1-B输出不属于δ认证。

今后若要主张期望样本复杂度最优，需要明确处理失败终止事件、几乎必然停止和尾部可积性，并给出完整证明。不能以本轮有限δ比值接近1替代这些条件。

## 来源与定位

[Degenne–Koolen, Pure Exploration with Multiple Correct Answers](https://arxiv.org/abs/1902.03475)给出了多答案下界和可达算法的核心框架。本草稿借助有限备择集，可以把难备择的选择拆成有限事件并使用高斯二次型集中。数学专门化不构成原创性认证；真正需进一步研究的仍是组合几何、mask限制及可用数值认证之间的关系。
