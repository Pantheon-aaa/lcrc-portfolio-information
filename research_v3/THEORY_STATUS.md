# 决策兼容性与证据闸门的理论状态

本研究使用有限、已知候选风险族，未知量是真实模型的身份。所有模型共用紧凸持仓域，目标为零均值 GMV 的半方差。本文中的证明是条件性研究推导；计算检查不能替代证明，也不能证明原创性。

## 已核验的兼容性结论

记 `V_j=min_W f_j`、`R_j=f_j−V_j`、`K_j(ε)={w:R_j(w)≤ε}`，以及 `Γ(G)=min_W max_{j∈G} R_j(w)`。连续性与紧性保证极小点存在。

**命题 A0。** 最大后验成功质量等于最大兼容子集质量：

`max_w Σ_j π_j 1{R_j(w)≤ε} = max_{G: Γ(G)≤ε} Σ_{j∈G} π_j`。

证明：任意持仓诱导的成功集合有该持仓作为共同见证；反过来，任意兼容集合有一个见证持仓，其实际成功集合至少包含该集合。两侧因此相等。这是有限机会约束／最大可行子系统的等价表述，不是新的统计保证。

**冲突割的有效性。** 若 `Γ(C)>ε`，任何兼容 G 都不可能包含 C，因此 `Σ_{j∈C} z_j≤|C|−1` 有效。Helly 保证仿射维度 k 中存在至多 k+1 个集合的空交证书；它不保证只检查模型对足够，也不保证冲突割算法多项式时间。代码只用严格的数值下界添加割；跨越 ε 的区间不能产生割。

**计算误差的方向。** 对 `V_L≤V≤V_U`，持仓的 regret 区间为 `[f−V_U,f−V_L]`。任意概率权重 q 给出

`V_L(Σq_jQ_j)−Σq_jV_{j,U} ≤ Γ(G) ≤ max_{j∈G}[f_j(w)−V_{j,L}]`。

因此确定成功使用 regret 上界，确定失败使用 regret 下界。float64 弱对偶检查包含舍入余量，仍不等于有向舍入的区间算术证明。

**hinge 缓冲界。** 对 γ>0，逐模型有 `1{R>ε+γ}≤[R−ε]_+/γ`，求后验平均即得概率上界。该界不说明 hinge 最优解等于成功概率最优解；E1 正是需要检验代理偏差的例子。

**MA 的地位。** `Σπ_jR_j(w)=½wᵀ(Σπ_jQ_j)w−Σπ_jV_j`，最后一项与 w 无关。因此同一正确后验下 MA 精确最小化后验均值 regret。固定真实模型上的重复抽样均值未必满足同一排序；Bayes 最优性不等于每个模型条件下都最优。

## E1 的不可能性与随机化

按附件的三个单位对角协方差构造，singleton 观测的联合密度完全相同，后验赔率不能更新。三个一阶最优响应形成正三角形：两模型中心的二阶系数为 3/8，全模型为 1/2，ε/t²=7/16 位于二者之间。有限 t 的不等式必须由独立数值上下界检查，不能只依赖渐近符号。

若三个模型的 ε-集合整体无交集，任意持仓至少在一个模型失败。同分布观测使随机算法输出在三种真模型下有同一分布，故三个失败概率之和至少为 1，最坏失败率至少 1/3。均匀随机选择三组 pair center，每个模型恰被两组兼容组合覆盖，达到最坏失败率 1/3。随机化是选取一个组合，不是平均三个组合；后者返回 MA，可能在三个模型上全部失败。

更一般地，在完全观测等价的有限模型族中，所有可实现的成功集合形成有限的向下封闭集合族。最小最坏失败率等于在其兼容集合之间随机化的有限线性规划值。证明只需把每个输出映射为其成功集合，再为每个集合选择一个见证。它是有限零和博弈的直接应用，不在本轮宣称为新主定理。

## B1 与已有多资产理论的对应

原 Theorem 6 的两组高斯协方差在组内方向有共同曲率；组内平均收益是模型区分的充分统计，其二维协方差为 `[[1,c],[c,4]]`。组内残差在两模型下分布相同且与组均值独立，似然比完全约去。

好市场 `c=1−t`，坏市场 `c=1.7`。令第二组总持仓为 x，则去掉共同常数后的目标为

`f_G(x)=½(3+2t)x²−tx`，`f_B(x)=½·1.6x²+0.7x`。

故 `x_G=t/(3+2t)`、`x_B=0`。不同曲率使等曲率示例的完整行动公式不适用。代码枚举 CVaR 的分段驻点、regret 交点和端点，并与高维凸规划核验。

在坏市场下 `E_B[p_G(D)/p_B(D)]=1`。以 `1/(δt)` 为批准门槛，Markov 给出错误批准率不超过 δt。误批到好模型 oracle 的损失为 O(t)，所以坏市场期望 regret 为 O(δt²)。好市场仍需要足够样本控制错拒；单有显著性不能推出高功效。本轮横轴保留 KL(t)，不把 t 变化时的信息量视为常数。

这是一侧 LR 检验，不能作为独立算法新颖性的依据。原 v2 的 Theorem 6 已证明特定双模型子类中对数信息阶的必要性与 CVaR 可达性；本轮不将其重复计算包装成新样本复杂度定理。

## B2 的条件安全证明

条件于 pilot 数据，基准 w_b、候选 w_c、危险集合 `B_c={j:f_j(w_c)>f_j(w_b)+ξ}`、辅助密度 q_c 和 δ_c 都固定。gate 数据与 pilot 独立。对任意危险真模型 j：

`批准 c ⇒ q_c(D_gate)/p_j(D_gate)≥1/(δ_ct)`。

q_c 是完整数据集密度的固定混合，积分为 1，因此条件错误批准概率不超过 δ_ct。对 c 求并集界并对 pilot 积分，得到“至少一个真实危险候选获批”的概率不超过 `tΣδ_c≤δt`。

在没有错误批准的事件上，所有获批候选及基准均满足 `f_j(w)≤f_j(w_b)+ξ`。共同凸目标保证其凸包中的任何组合也满足此不等式，即使组合系数使用 gate 数据再选择。因此最终优化可使用全部观测后验；被 gate 拒绝的候选不能重新进入优化域。

数值实现将不能确认安全的模型也纳入危险集合，所以只可能增加保守性。默认 ξ=0。该结论控制相对基准的恶化概率，不保证基准接近 oracle、不保证一般 ε-regret、不保证连续未知参数或非平稳收益，也不支持重复查看证据后沿用固定时点阈值。

## 尚未完成的论文增量

**同预算安全参照。** 补充 CS-Safe 使用 pilot 后验混合 q 与独立 gate 数据构造 `C={j:p_j≥αq}`，取 α=δt。对任意真模型，条件期望 `E_j(q/p_j|pilot)=1` 给出真模型被排除的概率至多 α。仅批准在 C 内每个模型都不恶化的候选，再在批准凸包内优化，便有同样的最终安全保证，无须逐候选分配 α/C。该参照采用所有候选共享的密度，B2 使用各候选自己的改善模型密度；二者的功效差别必须实测。CS-Safe 不是原有限 LCRC regret center，二者控制的事件不同。

1. 多模型联合冲突决定的信息复杂度，及与下界匹配的统一可达算法。
2. 比通用最大可行子系统更有效的结构化求解，或有一致性保证的可扩展代理。
3. 多方向、连续未知干扰参数下的证据效率，而不只是有限模型的 union bound。
4. 明确优于恰当安全基线的理论分离。较低错误率伴随更高错拒，不能称为全面优越。

## 文献对应

- [Degenne 与 Koolen，Multiple Correct Answers](https://arxiv.org/abs/1902.03475)：多正确答案的样本复杂度与可达方法已有直接理论。本项目的连续组合／被动 mask 实验需要给出额外结果，不能只借“多个答案”主张新颖。
- [Wasserman 等，Universal Inference](https://arxiv.org/html/1912.11436v4)：独立拆分似然比的有限样本有效性是 B2 的经典基础。本轮已对照其条件期望与 Markov 证明。
- [Hauser 等，Relative Robust Portfolio Optimization](https://arxiv.org/abs/1305.0144)：相对 regret 与有限情景稳健组合已有先例。
- [Lee 等，PEAR](https://proceedings.mlr.press/v306/lee26q.html)：固定局部活跃约束下的决策敏感性已有直接近邻。隐藏曲率和冲突信息仍需单独证明贡献。

上述核查是有针对性的定位，不是穷尽文献或原创性认证。
